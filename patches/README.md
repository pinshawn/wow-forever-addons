# 共用補丁

這裡放「改別人插件的一小段程式」的補丁。更新程式（v1.3.6 起）每次雙擊時會讀線上清單的 `patches`，
下載補丁檔（檢查碼要對），在你的電腦上把那個插件的檔案補好；補過了就不再補，被插件的新版蓋掉就再補一次。

- 補丁裡**不放原作者的程式碼**：要改的位置用「每一行的 SHA-256 檢查碼」認，補丁只寫我們改的部分。
- 原作者改到那幾行（檢查碼對不上）時，整個補丁不補、檔案不動，畫面會寫「套不上」。
- 補之前的原檔留在 `插件更新\本機補丁\補之前的原檔\<日期時間>\`。
- **作者自己修好了**：作者的新版本來就會整個蓋掉舊檔（補丁跟著沒了）；我們再把那個補丁標成停用（`"retired": true`），大家就不再補，不會擋到作者。
  補丁檔也可以寫 `maxVersion`＋`versionFolder`（只補到那一版），插件比它新就不補。
- 不想要補丁：`addons.json` 寫 `"sharedPatches": false`（全部不要），或 `"skipPatches": ["補丁 id"]`（某幾個不要）。
